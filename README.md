# Кошачий оракул

## Описание игры

"Кошачий оракул" — трпо проект игра "кошачий оракул". Пирамида молчала тысячелетиями. Теперь её тишину нарушают только ваши шаги и мурлыканье древнего духа, принявшего облик кота. Он — хранитель, а вы — ключ. Соберите магические кристаллы, расшифруйте послания на стенах и восстановите древнюю карту. В этой игре каждая загадка — это шаг к диалогу с прошлым, а найденная древняя реликвия — шаг к величайшему открытию.

## Инструкции по запуску

### Требования

- Python 3.7 или выше
- pip (менеджер пакетов Python)

### Установка

1. Клонируйте репозиторий или скачайте проект:
```bash
git clone <repository-url>
cd koshachi-oracyl
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

### Запуск игры

Запустите главный файл:
```bash
python koshachi_oracul/main.py
```

Или из корневой директории проекта:
```bash
cd koshachi_oracul
python main.py
```

### Управление

- **Мышь** — основное управление, взаимодействие с объектами
- **Клик по объектам** — взаимодействие с элементами игры
- **Инвентарь** — отображается на экране, клик по предметам для использования

## Особенности

- **Система аутентификации** — вход в игру через экран авторизации
- **Многоуровневая система комнат** — три уникальные комнаты с различными головоломками
- **Интерактивные головоломки**:
  - Головоломка с пирамидой и кирпичами
  - Домофон с числовым кодом
  - Головоломка двери со статуями
  - Интерактивные объекты в комнатах (вазы, сундуки, гробницы)
- **Система инвентаря** — сбор и использование предметов
- **Настройки музыки** — выбор музыкального сопровождения (оригинал, египетская, молитва) и включение/выключение звука
- **Система историй** — вводная и финальная истории с пошаговым отображением текста
- **Визуальные эффекты** — анимированные переходы и интерактивные элементы

## Технические характеристики

### Технологии

- **Язык программирования**: Python 3.7+
- **Игровой движок**: Pygame 2.6.1
- **Архитектура**: Объектно-ориентированное программирование

### Производительность

- **Разрешение экрана**: 1200x800 пикселей
- **Частота кадров**: 60 FPS
- **Оптимизация**: Использование спрайтов и эффективное управление ресурсами

### Структура проекта

```
koshachi_oracul/
├── main.py          # Точка входа, управление экранами
├── game.py          # Основная логика игры, управление комнатами
├── menu.py          # Главное меню
├── auth.py          # Система аутентификации
├── settings.py      # Меню настроек (музыка, звук)
├── pyramid.py       # Логика головоломки пирамиды
├── room1.py         # Первая комната
├── room2.py         # Вторая комната
├── room3.py         # Третья комната
├── door_puzzle.py   # Головоломка двери
├── button.py        # Компонент кнопки и текстового ввода
└── assets/          # Ресурсы проекта
    ├── *.png        # Изображения (фоны, объекты, UI)
    └── *.mp3        # Музыкальные файлы
```

### Модули и компоненты

- **Game** — основной класс игры, управляет переключением между комнатами и головоломками
- **PyramidPuzzle** — головоломка с кирпичами и домофоном
- **Room1, Room2, Room3** — отдельные комнаты с уникальными механиками
- **DoorPuzzle** — финальная головоломка с использованием статуй
- **AuthMenu** — экран авторизации с полями ввода
- **MainMenu** — главное меню с навигацией
- **SettingsMenu** — настройки музыки и звука
