# koshachi-oracyl
трпо проект игра "кошачий оракул". Пирамида молчала тысячелетиями. Теперь её тишину нарушают только ваши шаги и мурлыканье древнего духа, принявшего облик кота. Он — хранитель, а вы — ключ. Соберите магические кристаллы, расшифруйте послания на стенах и восстановите древнюю карту. В этой игре каждая загадка — это шаг к диалогу с прошлым, а найденная древняя реликвия — шаг к величайшему открытию.
